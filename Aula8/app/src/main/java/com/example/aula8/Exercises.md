## Exercício 3: Barra de Navegação Simples
- Layout: Utilize uma Row para organizar os itens de navegação
horizontalmente.
- Elementos: Três composables Text com bordas para aparentar
um botão. Coloque uma propriedade clickable que possua um
toast que exiba uma mensagem ao clicar no botão.
- Modifiers:
o Dê a cada botão algum padding.
o Faça a Row ocupar toda a largura disponível (fillMaxWidth()).
- Arranjo/Alinhamento: Use Arrangement.SpaceAround ou
Arrangement.SpaceBetween para distribuir os botões
igualmente pela largura. Centre o texto verticalmente dentro
de cada botão (se estiver usando Text).
